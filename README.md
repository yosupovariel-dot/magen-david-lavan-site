# מגן דוד לבן — אתר תדמית

אתר התדמית של מערך ההתנדבות הארצי **מגן דוד לבן** (magendavidlavan.com).
אתר סטטי בעברית (RTL): HTML, CSS ו-JavaScript נקיים, ללא ספריות צד שלישי, ללא עוגיות וללא מעקב.

## מבנה

```
src/
  data.json        ← כל התוכן המשתנה: טלפונים, סיירות, מפקדים, המלצות, קישורים
  layout.html      ← תבנית משותפת (כותרת, ניווט, פוטר, תפריט נגישות)
  pages/*.html     ← תוכן כל עמוד + מטא-דאטה (כותרת, תיאור ל-SEO)
tools/build.py     ← בונה את האתר לתיקייה docs/
docs/              ← האתר המוכן להעלאה (זה מה שמפרסמים)
  css/ js/ assets/ ← עיצוב, סקריפטים, תמונות (WebP), גופנים מקומיים
```

## עדכון תוכן

1. עורכים את `src/data.json` (למשל: מספר טלפון של סיירת, מנהל חדש, קישור לקבוצה) או את הקובץ הרלוונטי ב-`src/pages/`.
2. מריצים:
   ```
   python tools/build.py
   ```
3. מעלים את תוכן התיקייה `docs/`.

> אין לערוך ישירות את קובצי ה-HTML שבתוך `docs/` — הם נוצרים מחדש בכל בנייה. קובצי `docs/css`, `docs/js` ו-`docs/assets` נערכים ישירות.

## אחסון

- **Cloudflare Pages / Netlify (מומלץ):** תיקיית פרסום = `docs`. קובץ `docs/_headers` מפעיל את כל כותרות האבטחה (CSP, HSTS, X-Frame-Options ועוד).
- **GitHub Pages:** Settings → Pages → Branch `main`, תיקייה `/docs`. ב-GitHub Pages אין תמיכה בכותרות מותאמות, ולכן מדיניות ה-CSP מוגדרת גם בתגית meta בכל עמוד.

## SEO

כותרת ותיאור ייחודיים לכל עמוד, כתובות canonical, Open Graph, נתונים מובנים (Schema.org: NGO, BreadcrumbList), `sitemap.xml` שנוצר אוטומטית, `robots.txt`, תמונות WebP רספונסיביות, גופנים מקומיים וטעינה עצלה.
לאחר העלייה לאוויר: לרשום את האתר ב-Google Search Console ולהגיש את `sitemap.xml`.

## נגישות ומסמכים משפטיים

- תוכנן לפי ת״י 5568 / WCAG 2.1 ברמה AA; נבדק אוטומטית עם axe-core (ללא ממצאים) בדסקטופ ובמובייל.
- תפריט נגישות מובנה (ללא סקריפט חיצוני), קישור דילוג לתוכן, ניווט מקלדת מלא, תמיכה ב-prefers-reduced-motion.
- עמודים: `accessibility.html` (הצהרת נגישות), `privacy.html` (מדיניות פרטיות), `terms.html` (תנאי שימוש).
