# דף הנחיתה – מדרשת מעיין שדרות

`index.html` – הקוד המלא של הדף (להדבקה בווידג'ט HTML באלמנטור).

## תמונות חדשות – להעלות לוורדפרס

את כל הקבצים שבתיקייה `images/` מעלים לספריית המדיה של וורדפרס **בחודש נובמבר 2026**, בלי לשנות את שמות הקבצים.
הדף כבר מפנה לכתובות מהסוג:

```
https://sderot.org/wp-content/uploads/2026/11/<שם-הקובץ>
```

אם מעלים בחודש אחר (או שוורדפרס משנה את שם הקובץ) – מחליפים בקוד את `2026/11/` בתיקייה הנכונה.

| קובץ | איפה מופיע |
|---|---|
| `mdr-pillar-depth.webp` / `mdr-pillar-group.webp` / `mdr-pillar-provision.webp` | אודות – עומק / חבורה / צידה לדרך |
| `mdr-program-group.webp` | התמונה ליד "מה מחכה לך בשנה הזו" |
| `mdr-card-hoshana.webp` + `mdr-flyer-hoshana.webp` | כרטיס "ימי עיון" + הפרסום המלא |
| `mdr-card-masa.webp` + `mdr-flyer-masa.webp` | כרטיס "מסע לנשמה" + הפרסום המלא |
| `mdr-card-lectures.webp` + `mdr-flyer-lectures.webp` | כרטיס "שיעורים פתוחים" + הפרסום המלא |
| `mdr-schedule.webp` | קישור "למערכת המקורית כתמונה" |

## מקומות שמחכים לתמונה

- **באנר "בתיכון הובילו אותך"** – מחפשים בקוד `quote-photo` ומדביקים כתובת תמונה בתוך `src=""`. הבאנר יתחלק אוטומטית לטקסט + תמונה.
- **פרסום יום פתוח** – מחפשים בקוד `id="openDay"` ומדביקים כתובת תמונה בתוך `src=""`. הפרסום יופיע באזור "צור קשר" ויוגדל בלחיצה.

## מערכת השיעורים

המערכת בנויה כטבלה בקוד (ולא כתמונה): טבלה מלאה במחשב, ולשוניות לפי יום בטלפון.
לעדכון – מחפשים בקוד `var SLOTS=` ומשנים את שם הרב/ה או השיעור בשורה המתאימה.
